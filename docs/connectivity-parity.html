Связь с сервером: Android приводим к web

Один и тот же Go-прокси, но у приложения была своя жизнь: разовая проверка здоровья, тихий обрыв SSE, пустые чаты при создании, замена транскрипта вместо склейки. Теперь есть холодный кэш только отображаемого, ленивые шаги и живой таймер хода.

Четыре пути, где поведение расходилось

Старт приложения

health один раз → нет сети → логин
↓ стало
cookie → приложение открывается → health каждые 20 с
↓
2 провала → офлайн-баннер + «повторить»

Обрыв SSE

readTimeout = ∞ → тихо висим
↓ стало
ping 20 с, timeout 45 с → CLOSED
↓
пауза 0.5–8 с с джиттером → OPEN
↓
догон: сообщения + сессии + формы

Новый чат

POST /sessions сразу → пустой чат в списке
↓ стало
локальный «новый чат» → первый промпт
↓
POST /sessions с agent и model → prompt
↓ стоп до ответа
DELETE пустого чата → текст назад в композер

Перезагрузка транскрипта

ответ сервера заменяет весь список
↓ стало
снимок + сообщения, изменённые стримом, склеиваются
↓
старые страницы: дедуп и защита от устаревшего ответа

Ход агента

точка «работает» без деталей
↓ стало
спиннер · таймер · счётчик шагов · текущее действие
↓
«Шаги · 12» → полное сообщение по клику, в кэш не пишется
