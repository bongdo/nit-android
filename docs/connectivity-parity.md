# Связь с сервером: Android против web

Сверка `app/src/main/java/space/bongdo/nit` с `../nit-gui/web/src` по всему, что
касается транспорта: старт, SSE, создание чатов, догрузка, восстановление.

Статус: **сделано** — поведение приведено к web; **осталось** — расхождение
осталось сознательно; **совпадает** — и раньше работало одинаково.

## 6. Что осталось и почему

- **Нет кэша и предзагрузки (5, 31, 33).** Осознанное решение: сервер — источник
  правды, на телефоне не хочется качать все чаты и держать второй кэш.
- **Нет инстансов (6, 12).** В приложении один адрес сервера; экран инстансов не
  входил в мобильный сценарий.
- **Нет склейки дельт (13).** Приложение обновляет Compose на каждое событие.
  При медленном рендере это даст лишние кадры; лечится буфером на 30–50 мс.
- **Нет снятия выбора удалённого чата (26).** Список не содержит субагентов,
  поэтому «нет в списке» ≠ «удалён».
- **Фоновый опрос только по таймеру (36).** При возврате из фона ждём до 5 с.
